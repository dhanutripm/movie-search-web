#  CineSearch - Movie Search Web Application

A feature-rich movie search web application developed as part of minor project coursework. The application fetches and displays real-time data using public APIs, utilizing asynchronous JavaScript, API integration, and dynamic DOM manipulation[cite: 2].

---

## Project Requirements Implemented

* **Movie Search API Integration:** Search movies seamlessly using a public movie database API[cite: 2].
* **Poster & Detail Display:** Display movie posters and detailed information dynamically[cite: 2].
* **Ratings & Release Info:** Show movie ratings and release information clearly within an interactive modal view[cite: 2].
* **Error Handling:** Gracefully handle invalid search queries and network or API errors[cite: 2].
* **Responsive UI:** Fully responsive user interface optimized for mobile, tablet, and desktop viewports[cite: 2, 3].
